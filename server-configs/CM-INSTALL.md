# CM adjustments (formerly cm-install.sh)

**Now merged into `app/scripts/jobs.sh`** (function `cm_adjustments`, between the markers
`# >>> BEGIN cm-adjustments >>>` / `# <<< END cm-adjustments <<<`, comment "added by CM").
jobs.sh ships with every update and runs the CM adjustments automatically in its `restart_jobs`
step after every update, on plain and Docker servers.

| Step | What |
|---|---|
| FreeSWITCH scripts | `call-control/ringq_call_control.lua`, `queue-strategy/callcenter.conf.lua` |
| Database | `q_call_center_tier_order`, `q_call_journeys` (created if missing) |
| Dialplans | `ringq-call-control` (order 36), `ringq-trunk-media-timeout` (order 37), and `local_extension` restored when an update has reset it to the FusionPBX stock version |
| Health check | `/usr/local/sbin/ringq-health.sh` + `/etc/cron.d/ringq-health` |
| nginx | LAN provisioning route `/provision/2db3f557e1d6/` on port 80 (private networks only) |

Idempotent and non-fatal: every step checks first and only changes what is missing or wrong;
replaced files are backed up to `/var/backups/ringq-cm-install/<time>/`. No restarts: FreeSWITCH
XML is reloaded only when a dialplan changed. Log: `/var/log/ringq-cm-install.log`.

    bash /var/www/ringq/app/scripts/jobs.sh --cm-adjust --check   # report only (exit 1 if anything needs fixing)
    bash /var/www/ringq/app/scripts/jobs.sh --cm-adjust           # install / repair
    bash /var/www/ringq/app/scripts/jobs.sh --cm-adjust --force   # also replace a customised local_extension

`server-configs/cm-install.sh` is kept as a thin wrapper for the same command (Docker host: it
runs inside the `ringq` container).

## Editing

The files in `server-configs/*/` and `node/q_call_journeys.sql` are the editable sources; jobs.sh
carries embedded copies generated by `server-configs/cm-embed.py`. After any change:

    python3 server-configs/cm-embed.py            # regenerate the block in jobs.sh
    python3 server-configs/cm-embed.py --verify   # exit 1 if jobs.sh is out of date (CI)

Commit jobs.sh together with the changed source file.
